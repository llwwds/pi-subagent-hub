# pi-subagent-hub v2.1.0.0（源码发布候选）

状态：**源码状态，未发布、未部署**。本仓库没有对应的 GitHub Release，也没有 tag。源码与独立部署不自动同步：本文件描述的改动不会进入任何现有部署，也没有替换或验收任何现有部署。

## 相对 v1.0.0.0 的主要变化

### 多载体

- 统一载体接口：`pi`、`codex`、`claude`，每个 Agent 保留独立 ID、状态、会话与日志。
- Pi 使用长驻 RPC 进程；Codex CLI 与 Claude Code CLI 每轮启动一个进程并续接私有会话。
- 载体能力通过 `GET /v2/carriers` 暴露，可用性只在启动条件层面诊断，不代表真实模型调用已通过。

### Skill 授权与 Skills Manager

- Skill 快照复制到平台私有存储，按内容 SHA-256 固定；创建时冻结授权，后续导入不扩权。
- Skills Manager 1.41.0 通过 CLI 手动连接（`/v2/skills/manager`、`pihub skills manager ...`），同步只读管理器目录，不部署、不改写全局库；未连接时使用平台已有快照。

### System Prompt 注入

- 四项编码原则默认勾选，可全部取消、任意组合，并可追加自定义正文。
- 只使用追加通道：Pi / Claude 为 `--append-system-prompt`，Codex 为 `-c developer_instructions`（额外 developer 指令层，经 `codex debug prompt-input` 定点核验，不覆盖 base 指令）。
- 冻结记录写入 Agent 私有状态文件与 `agents.prompt_config_json`，重启复用，`inspect` 可查通道、原则、字符数与摘要。

### 日志与事件

- 语义事件写 SQLite；流式增量（`message_update` 等）不落库、不写入诊断日志，最终 `message_end` 完整保留。
- 每个 Hub home 只有一个 `hub.log` 文件族（旋转、总量上限、背压丢弃），取代每 Agent 的 `appendFileSync` 协议日志与无界 stderr 文件。
- daemon 退出时等待 `closeLogs()` 刷新后关闭流。

### 面板

- 创建 Agent 时可选载体、供应商、模型、Skill 范围、System Prompt 原则与正文。
- 详情页展示追加通道、原则、正文摘要与冻结 digest。
- Skill 广场新增 Skills Manager 手动连接区（连接 / 同步 / 断开），未连接时明确提示不会自动连接全局库。

## 兼容性

- `/v1` HTTP 路由、`pihub spawn|list|inspect|prompt|logs` 与 manifest `schemaVersion: 1` 响应形状保持不变。
- `agents` 表新增 `prompt_config_json`（`TEXT NOT NULL DEFAULT '{}'`）；既有库只做 `ALTER TABLE ADD COLUMN`，不重写历史行与事件。
- 新能力通过 `/v2` 路由与 `pihub agents|skills|prompts|carriers|providers` 命令提供。

## 发布前修复（仍未提交、未升版本）

- `GET /v2/agents/:id` 现在返回完整的冻结 `promptConfig`（正文、`principleIds`、`channel`、`digest`），供详情面板直接展示；`/v1` 路由保持原有形状，不暴露 `promptConfig` 或原始 SQL 列。列表视图（`/v2/snapshot`）仍只给摘要与 digest。
- Skills Manager 连接的路径校验允许管理器库经过系统别名（macOS `/tmp` -> `/private/tmp`）：快照保存规范化的 `entryPath`，解析时同时接受字面根与规范根，并逐段用 `lstat` 拒绝库内符号链接与越界路径。`TMPDIR` 为默认值或 `/tmp` 时 `npm run check` 均为 83 项全通过。
- 流式增量（`tool_execution_update`、Codex `item.updated`）已按纯增量过滤，`message_end` / `tool_execution_end` / `item.completed` / 错误与终态继续持久化。

## 已知限制

- `all` / `only` Skill 范围只限制平台自动加载的 Skill，不是文件或网络隔离。
- Codex `developer_instructions` 是 developer 层附加指令，不是 system prompt；`model_instructions_file` 属替换语义，平台不使用。
- Hub 日志单写者假设：同一 `PIHUB_HOME` 只能由一个 daemon 写。
