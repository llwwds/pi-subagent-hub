# pi-subagent-hub v1.0.0.0

首个公开稳定版。

## 主要能力

- 通过 CLI 或批量 manifest 拉起任意数量的独立 Pi subagent。
- 每个 subagent 拥有独立进程、session、context、日志和生命周期。
- 共享同一份冻结的 tool/skill profile，并可分别选择 provider、model 和 thinking level。
- 提供统一的本地网页面板，以及适合 Agent 调用的稳定 JSON 输出。
- AI API endpoint、协议、凭据引用和模型列表只需修改共享 `models.json`，不需改代码、重新构建或重新部署。

## 可复现性

- Pi Agent：`v0.85.1` / `d981de1229ef899957bbe968bc8dcda02a21f477`
- Node.js：`>=22.19.0`
- 运行依赖通过提交的 npm lockfile 和 `npm ci` 安装。

本 Release 仅发布 GitHub 自动生成的源码包，不包含本机配置、凭据、会话、上游源码 checkout 或预构建 `node_modules`。
